# Escape Tsunami Live Server Page

1. Open encode.html on your computer, paste your private server link, press Encode, and copy the result.
2. Replace the contents of config.js with that result.
3. Upload index.html, config.js, bg.mp4 and theme.jpg to a GitHub repo (not encode.html).
4. Repo > Settings > Pages > Deploy from a branch > main / (root) > Save.
5. Live at https://YOUR-USERNAME.github.io/REPO-NAME/
